# Roisalen Frontend

roisalen is a simple app for managing meetings. This is the frontend.

## INSTALLING:
1. First setup the backend.
2. Clone this repo.
3. The API URL comes from `VITE_API_URL` (e.g. `VITE_API_URL=http://localhost:8080 npm run dev`). Without it, the app calls `/rest` on its own host, or `https://roisalen.no/rest` on localhost.

## Developer tips

If you want to set it up locally, use

```
npm run dev 
```
